ThorVG WASM video layer

This page loads the local ThorVG WebAssembly bundle, renders a Lottie x-video image layer, and paints ThorVG's software buffer into this browser canvas.

Video Approach

The Lottie stays vector-native while ThorVG receives decoded video frames through its provider hook.

Lottie
The JSON defines a normal image layer whose asset carries x-video MP4 metadata.
ThorVG
LottieVideoProvider opens that asset and asks for a bitmap at the current animation time.
Browser
A hidden video element decodes the MP4; a hidden canvas copies RGBA pixels into WASM memory.
Composite
ThorVG treats the supplied bitmap like the image layer, so transforms, masks, and crops stay in Lottie.
Output
ThorVG renders the full 1280x720 software buffer, then JavaScript blits it to the visible canvas.
